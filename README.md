# Personal Web Page - Assignment 1

A simple personal web page created using HTML, CSS, and JavaScript.

## Project Description

This is a personal portfolio website that showcases information about me, including my strengths, weaknesses, bucket list, and favorite media content. The website is built as part of the Web Programming course assignment.

## Features

- Personal profile picture with clickable social media link
- About Me section with strengths and weaknesses
- Bucket list table showing personal goals
- Embedded video and audio players
- Interactive button with JavaScript functionality
- Hover effects on profile picture
- Responsive and clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## File Structure

personal-webpage/

## How to View

1. Download all files
2. Make sure all files are in the same folder
3. Open `index.html` in any web browser
